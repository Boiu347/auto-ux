# 百度云页面合同

## 页面预检

- 域名必须是 `ky.cloud.baidu.com`。
- 记录当前窗口、标签页、路由和稳定页面标记；执行期间不得自行新开标签。
- 只通过语义标签、可访问名称、稳定属性和回读内容定位控件，不记录屏幕坐标。
- 页面结构无法匹配时标记适配器不兼容并停止，不做坐标猜测。

## Target Guard

新建后保存 `agentId + robotId + robotName`。每次写操作前，从当前页面重新读取三者并逐项比较。缺失或不一致均停止。任何旧机器人都不属于允许目标。

## Encoding Guard

以 Unicode 写入。保留原始换行和标点；对平台允许的规范化进行明确记录。写入后回读，比较规范化值和哈希。第二次仍不一致时停止，并保留当前新机器人中的安全快照。

## 发布与语音

- 发布前验证发音人、开场白、音量和试听结果。
- 区分保存草案、提交发布和平台发布成功；只有明确成功状态才能进入号码流程。
- 不依赖界面默认值。拨测前显式核对语音电话、真实电话、主叫线路和脱敏被叫。

## 结果核验

弹窗关闭只说明 UI 状态变化。最终结果必须来自平台外呼记录，至少保存记录 ID、时间、脱敏被叫和状态。状态映射必须保留原平台含义，无法映射时使用 `unknown`。
