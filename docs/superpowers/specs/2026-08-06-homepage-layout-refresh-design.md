# 首页布局改版设计

日期：2026-08-06

## 目标

在不改变业务字段、提交逻辑、配对流程和任务详情页的前提下，减少首页无效留白，重建清晰、紧凑的控制台信息层级。

## 设计判断

这是面向内部操作人员的 B2B 控制台首页。继续使用现有 Fluent UI，以可信、克制、效率优先的产品界面为方向。设计变化幅度中等，动效保持最低，信息密度从偏松散提升到中等。

## 页面结构

- 顶部改为紧凑的品牌栏与说明区，标题、说明和运行状态在同一视觉区域内完成表达。
- 主体使用非对称双栏：左侧为流程说明、隐私边界和任务列表，右侧为主要任务表单。
- 主要任务表单占据视觉主位，不再受 900px 宽度限制，也不再漂浮在大面积空白中。
- Mac 配对卡在启用时进入左侧辅助栏；开发环境未启用时显示静态的三步流程说明。
- 空任务列表改成轻量分区，不再使用一个尺寸偏大的禁用卡片。

## 视觉规则

- 保留 Fluent UI 和现有蓝色品牌色，不新增依赖。
- 页面最大宽度 1360px，桌面双栏比例约为 0.72:1.28。
- 卡片统一 14px 圆角、细边框和浅色品牌阴影；辅助信息优先使用浅底分区而非重复卡片。
- 桌面端减少顶部与卡片外边距；768px 以下折叠为单栏，表单优先展示。
- 不修改任何字段名称、按钮意图、链接、接口或状态逻辑。

## 验证

- 组件测试确认首页具备新的主内容区、辅助栏和流程说明语义。
- 运行 Web 测试、类型检查和构建。
- 在 1440px 与移动端视口核对留白、表单宽度和折叠顺序。
