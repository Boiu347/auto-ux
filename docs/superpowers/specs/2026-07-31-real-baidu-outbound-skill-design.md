# 百度云外呼真实一键配置 Skill 设计

## 目标

为 Codex 提供一个可安装、可复用的 Skill。用户提交飞书研究方案、会议纪要、问卷或本地号码资料后，Codex 使用当前用户的飞书 CLI 登录态读取资料，使用当前用户已登录的百度云浏览器会话新建并配置外呼机器人，并在三个高风险动作前分别等待本人确认。

第一版执行到启动拨打，并根据百度云真实呼叫记录区分提交、振铃、接通和失败。Skill 不修改已有机器人，不把提交成功描述为接通成功。

## 分发方式

- 仓库路径：`skills/configure-baidu-outbound/`
- 当前用户安装路径：`~/.codex/skills/configure-baidu-outbound/`
- 团队成员从 GitHub 仓库安装同一版本。
- 使用飞书 CLI 创建一份以需求方口吻编写的 Codex 使用说明书。

## 产物结构

```text
skills/configure-baidu-outbound/
├── SKILL.md
├── agents/openai.yaml
├── scripts/
│   └── validate_run.py
└── references/
    ├── baidu-routes-and-fields.md
    ├── configuration-contract.md
    └── recovery-and-evidence.md
```

`SKILL.md` 保留必须按顺序执行的主流程和停止条件。详细字段、页面路由、证据规则与恢复策略放入引用文件。`validate_run.py` 只做确定性输入校验和本地运行清单生成，不保存飞书原文、浏览器凭据或完整号码。

## 能力预检

每次任务开始时只初始化一个执行会话，并完成以下检查：

1. 定位 `lark-cli`。若普通 PATH 未找到，检查已知安装位置和登录 shell；不得猜测命令成功。
2. 使用只读命令检查现有飞书登录态。只有令牌失效、缺少权限或 CLI 不存在时才要求用户操作。
3. 确认浏览器控制能力可用，并复用一个已登录百度云标签页。
4. 将允许域名限制为 `ky.cloud.baidu.com`，将目标管理页和实际机器人编辑页登记到本次运行清单。
5. 确认用户要求新建机器人。Skill 不允许选择或修改已有机器人。

预检不通过时输出精确缺失能力并停止，不反复安装插件、授权飞书或打开新标签页。

## 真实执行流程

1. 接收任意数量的飞书研究方案、会议纪要、问卷链接或用户指定的本地资料。
2. 仅通过飞书 CLI 读取飞书内容，提取调研对象、业务背景、问卷问题、跳题关系、话术约束和预期时长。
3. 生成结构化配置草案，展示来源对应关系、缺失信息和冲突；用户确认草案版本后才进入百度云。
4. 在登记的百度云管理页新建机器人，记录新机器人名称和页面身份。
5. 配置角色、外呼人群、外呼目标、对话规则、开场白、挂断策略、挂断词、语音及其他必要字段。
6. 每次写入后逐字段回读。中文乱码、字段截断、页面身份变化或保存状态未知时立即停止。
7. 展示发布前差异和回读证据，等待本人确认发布。
8. 发布后再次回读发布状态。未知状态不得视为发布成功。
9. 询问号码来源是单个号码还是号码文件。解析后仅展示数量、重复数、无效数和脱敏样例，等待本人确认导入。
10. 导入后回读成功数、失败数和批次身份；不一致时停止。
11. 展示外呼批次、机器人、号码总数和脱敏样例，等待本人确认启动拨打。
12. 启动后查询真实呼叫记录，分别报告提交、振铃、接通和失败，不进行推测。

## 三个独立确认门

| 确认门 | 确认内容 | 失效条件 |
|---|---|---|
| 发布 | 机器人身份、配置版本、差异和字段回读 | 配置变化、页面变化、机器人变化 |
| 导号 | 来源类型、总数、无效数、重复数、脱敏样例 | 文件变化、号码变化、发布状态变化 |
| 拨号 | 机器人、批次、号码总数、脱敏样例 | 批次变化、号码变化、页面或登录态变化 |

每次确认只能由当前本人完成，只能使用一次，不能跨动作、跨机器人或跨配置版本复用。

## 导航与会话不变量

- 一个任务只使用一个 Codex 执行会话和一个百度云工作标签页。
- 飞书链接只交给飞书 CLI；百度云页面只交给浏览器控制工具。
- 禁止把 URL 输入搜索引擎，禁止打开 Google 或搜索结果页。
- 当前地址不属于允许域名、缺少协议或页面身份无法确认时立即停止。
- 插件或工具已经可用时必须复用，禁止重复安装、重复初始化或重复授权。

## 数据与证据

- 飞书原文只在本地任务上下文中使用，不写入控制面或 Skill 运行清单。
- 完整号码只保留在用户提供的本地来源和百度云导入过程，不写入运行清单或日志。
- 证据只保存字段名、脱敏摘要、页面身份、时间和结果状态。
- `unknown` 保持为 `unknown`，不得转换成成功。
- 只有百度云真实呼叫记录可以证明振铃、接通或失败。

## 错误与恢复

- 字体乱码：停止写入，保留原页面，不清空或覆盖其他字段；从最后一次已验证字段恢复。
- 错误网站或标签页：停止，不在地址栏拼接或搜索；回到登记的百度云标签页并重新验证页面身份。
- 会话过期：提示用户在原标签页恢复登录，之后从只读回检开始，不重复创建机器人。
- 操作结果未知：查询页面或记录确认，不重复点击发布、导入或拨打。
- 号码不一致：重新解析来源并重新请求导号、拨号确认。
- 机器人身份不一致：停止任务，禁止继续操作或尝试修改目标。

## Skill 验证

先用无 Skill 的基线场景验证其他 Codex 容易出现的失败：重复初始化、浏览器读取飞书、错误域名、跳过确认、把提交当接通。再加载 Skill 运行相同场景，要求 Codex 正确停止、选择工具并输出确认摘要。

验证不触发真实发布、号码导入或拨号。真实系统验收使用专用测试机器人和测试号码，并分别由用户确认三个高风险动作。

## 飞书说明书

说明书以需求方口吻编写，面向第一次接手的 Codex 和安装者，包含：

- 这个 Skill 解决什么问题以及不解决什么问题。
- 安装路径、触发语句和所需能力。
- 飞书 CLI 与百度云登录态检查。
- 完整执行顺序和三个确认门。
- 进度状态、停止条件、故障恢复和禁止事项。
- 一次从研究方案到测试拨号的示例请求。
- 当前版本号、GitHub 来源和升级方式。
